# 《千锤百炼之后，最难，是被看见》口播视频工程

竖屏 1080×1920 / 30fps / 约 9 分 15 秒。全部画面、配音、配乐、音效均由本目录代码生成，可一键重建。

## 导演思路

**两个世界的对照**贯穿全片：

| | 慢的世界（手艺 / 作品） | 快的世界（流量 / 商品） |
|---|---|---|
| 画面 | 宣纸肌理、水墨、思源宋体、暖灯、朱砂印章 | 霓虹粉青、粗黑体、贴纸、RGB 错位、扫描线 |
| 节奏 | 慢推镜、逐字浮现、留白 | 硬切、闪白、抖动、贴纸按拍弹出 |
| 声音 | 竹笛、古筝、钢琴、弦乐、五声音阶 | 廉价电子鼓、808、提示音、故障音 |

设计师女生博客的版式语言：杂志式页眉页脚与裁切角标、`FIG.01` 图注、手写批注圈画、
勾选/划掉清单、章节扉页（大号描边数字 + 中英标题），全片 6 章：

0. 冷开场：千锤百炼（四声铁砧，字字落锤）→ 最难 → 聚光灯揭开“被看见”；“太安静了”与“太会造势了”的一静一闹
1. 深夜直播间：00:12 的月洞窗 → 手机划到竹笛直播 → 老师傅原话竖排毛笔字，“一刀一刻”两道刀光 → 在线人数 7 → 8（是我）
2. 两条赛道：竹笛 / 游戏美术分屏 → 耗时间·耐寂寞·慢打磨·不讨巧（四记鼓 + 四方印）→ 嘉奖被打叉 → 商品卡对比 → AI 套图铺满屏
3. 二十年：20 本速写本叠起 → 像素化溃散 → 心电图（与心跳音效同步）→ 迷茫的雾
4. 走出去：三月日历翻页、“美术”方框被打破 → 便利贴按词拍上 → 时代浪潮 → 散点连成一条路
5. 根：开箱画册 → 种子扎根、发芽 → 复印机“无法复制”三连（逐次加强）→ 两条赛道合一
6. 被看见：光点涌入又熄灭 → 商品 vs 作品（印章 + 全片最强一拍）→ 静默的“只是” → 一点光扩散满屏，直播间人数暴涨 → 片尾印章

所有画面动作、音效、配乐重拍都锚定在**配音逐字时间轴**上（`cues.py`），同一个词上画面、音乐、音效同帧落下。

## 配乐与音效

- 全片只用一个音阶：D 宫 / B 羽五声调式（D E F♯ A B）。一条 8 小节竹笛主题贯穿全片：开场埋下种子，
  手艺段落零碎出现，画师段落转为大提琴小调后被 AI 故障音打断，「合一」段落第一次完整奏出，
  「音色」段落由竹笛独奏，结尾以钢片琴轻轻引用。
- 「流量世界」用刻意廉价的电子乐（808、超锯齿波、四拍底鼓、提示音）；凡是要求静音的地方
  （太安静了、刀切之后、「只是」等）都是真正的数字静音。
- 音源：FluidSynth + GeneralUser GS 音色库（构建时自动下载）。鼓、合成器、氛围铺底和 69 种音效
  全部用代码合成，每一下都对准 `cues.py` 里标注的那个字。
- 混音：人声做压缩、齿音处理和临场感提升；配乐跟随人声自动避让（说话时压低约 8dB，句间空隙回升）；
  成片响度 -14 LUFS，真峰值 ≤ -1 dBTP。

## 配音为何“不读错”

- 引擎：Kokoro v1.1-zh（离线，女声 zf_003），由我们直接驱动 ONNX 模型。
- 前端：复用 Kokoro 训练时的 misaki 中文前端（jieba 分词 + pypinyin + PaddleSpeech 变调），
  再叠加本稿专用的多音字表 `tts/frontend.py`：调笛子/调试/精调/调音 *tiáo*、着 *zhe*、民乐 *yuè*、
  阴干 *gān*、噱头 *xué*、白发 *fà*、了解 *liǎo*、独一无二 *yī*、一辈子 *yí bèi zi* 等，以及跨词“不”变调。
- 每个字最终读音写入 `build/pinyin.txt` 供人工复核；`tts/verify_narration.py` 用 SenseVoice 语音识别逐句回听比对。
- 原稿中的笔误已修正后再配音：“停留了了许久”→“停留了许久”、“直播间里却驻足停留的人却不多”→“直播间里驻足停留的人，却不多”、
  “虽然在3年前就在开始使用AI在工作中”→“虽然三年前就已开始在工作中使用AI”。

## 重建

```bash
bash setup.sh          # 一次性：Python 依赖 + 模型（GitHub release 下载）
bash build.sh          # 配音 → 时间轴 → 配乐/音效/混音 → 字体 → 渲染 → 合成
# 成品：output/千锤百炼之后_最难是被看见.mp4
```

常用调整：
- 换声音 / 语速：`script.py` 的 `VOICE_SID`、`SPEED_SCALE`，或单句 `speed` / `pause`
- 改读音：`tts/frontend.py` 的 `PHRASES`（变调前）或 `FINAL`（变调后，绝对读音）
- 改画面：`visual/scenes.js`（每个场景一个 `SC.xxx`），预览单帧：
  `BUILD=build node visual/render.js preview /tmp/p 12.5 88.0`

## 目录

```
script.py              分镜台词：每句的屏幕文字、实际朗读、语速、停顿、场景、配乐段落
cues.py                剪辑决策表：配乐段落 + 246 个音效点，全部锚定到词
tts/                   自研中文前端 + Kokoro 推理 + 逐句识别校验
audio/                 配乐（FluidSynth + 合成）、音效合成、混音母带（-14 LUFS）
visual/                Canvas 动态图形引擎、61 个场景、Playwright 逐帧渲染
```
